## Limites da verificação

- Textos lidos de READMEs e metadados públicos, sem verificar todos os commits de código de cada aplicativo.
- O portal consulta Releases e tags sob demanda para distinguir arquivos APK efetivamente anexados de Artifacts temporários.
- Em ambientes com limite da API do GitHub, o site usa este instantâneo local, que não pretende ser sincronização automática de descrições.
- Repositórios privados, ausentes ou não publicados não entram na contagem pública.
