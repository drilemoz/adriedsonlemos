Curiosidade para aprender. Vontade de colocar em prática.

Etapas como Alfa, Beta ou Em testes descrevem o estágio informado no catálogo, não certificam a estabilidade do APK. Versões são consultadas nas Releases ou tags públicas do GitHub, identificadas separadamente. O download direto aparece apenas para APKs anexados a Releases públicas. Arquivos do GitHub Actions são temporários, podem exigir login e normalmente vêm em ZIP. Quando um projeto não possui Releases, mostramos o README ou as compilações disponíveis, sem inventar APKs.
