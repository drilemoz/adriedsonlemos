GitHub Manager

Administração de repositórios, Actions, Releases e arquivos do GitHub no Android.

Abrir repositório ↗

O que é o projeto

O GitHub Manager ajuda a acompanhar projetos e operações no GitHub diretamente no celular, incluindo arquivos, sincronização de ZIPs, builds, Releases e configurações de repositórios.

Principais funcionalidades

  • Consulta e administração de arquivos e repositórios com controle de permissões.
  • Visualização e acompanhamento de GitHub Actions, logs, Artifacts e Releases.
  • Pré-verificações de integridade e identidade antes de enviar código ou importar Secrets.

Limitações e requisitos

Algumas operações dependem de autenticação e permissões adequadas. O aplicativo não garante que um APK gerado esteja validado em aparelho, e nem toda build oferece download público.

Documentação e validação

As regras de segurança, versões, testes e correções ficam documentadas no README e no histórico do repositório.
